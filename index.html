@meng-xi/uni-routeruni-app 路由管理

为 uni-app (Vue 3) 提供类似 vue-router 风格的路由管理系统

快速开始
了解更多
GitHub
🧭

路由导航

push / replace / relaunch / back 四种导航，自动识别 TabBar，声明式 RouterLink

🛡️

路由守卫

全局前置/解析/后置守卫与路由独享守卫，guardRoute 冷启动补执行，InterceptorPlugin 拦截原生 API 确保全拦截

📦

参数传递与查询增强

params 传递复杂数据不暴露 URL，back() 后自动保留，queryInt / queryNumber / queryBool 便捷解析

📡

页面间通信

events 与 eventChannel 双向通信，useUniEventChannel 支持所有导航方式，粘性缓存不丢失事件

🧩

声明式组件

RouterLink 导航组件 + TabBar / TabBarItem 自定义底部导航，SCSS 变量与 CSS 自定义属性主题定制

🔄

路由状态自动同步

install 时注入全局 Mixin 自动调用 syncRoute()，浏览器后退、物理返回键等场景自动同步，无需手动处理

⚠️

错误处理

RouterError / NavigationFailure / UniApiError 完整体系，onError 全局捕获，isNavigationFailure() 精准判断

🎬

导航动画

导航动画参数与路由级 meta.animation 默认值，仅 App 端生效

💪

TypeScript 优先

完整类型定义与组合式 API，useRouter / useRoute / usePageChannel / onBeforeRouteLeave / useLink，与 Vue 3 无缝集成
